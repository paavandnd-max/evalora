Evalora connects each team’s GitHub project to the event problem statement, checks the repository’s structure and supported tests, and gives authorized judges a private evidence-based report.

How evaluation works

Event staff review the extracted problem statement and approve the criteria before submissions are evaluated.

1
Problem statementStaff create an event and review the extracted PDF or DOCX text and proposed criteria.
2
Repository inspectionEvalora identifies files, manifests, languages, and tests. Unsupported execution is reported clearly.
3
Private reviewJudges see test outcomes, security checks, evidence, and criteria alignment for assigned events.

Submit a repository

Choose an open event and submit the team name with the full public GitHub repository URL. No participant account is needed.
